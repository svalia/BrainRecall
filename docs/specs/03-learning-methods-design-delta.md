## 2. Задача и принципы

Пользователь должен тренировать извлечение без источника, возвращаться после перерыва, различать сопоставимые способы решения, объяснять своим языком и строить/проверять смысловые связи. Усложняем учебную задачу только в пределах возможностей, не интерфейс. Подсказка разрешена всегда, но её использование видно в результате. Создание группы/чтение карты не означают освоение.

Одна доминанта на состояние: сначала самостоятельная попытка → затем feedback → при пробеле помощь → корректирующая попытка. Не размещать эталон или готовую схему рядом с первым вопросом. Пользователь без материала/группы/ИИ проходит ручной путь; не заставлять пройти все пять методов до первого результата.

## 4. Новые экраны

### D40 — Смысловая группа

Job story: «Когда помню отдельные факты, хочу увидеть общий принцип и проверить, распознаю ли его в новой ситуации».

Вход D08 или контекст группы из D09; родитель всегда D08, временный просмотр из занятия реализуется overlay с возвратом в то же задание. Сверху название, принцип/условия и источник; ниже 2–7 участников с короткими подписями, направленными отношениями и примерами/контрпримерами. Главный CTA «Практиковаться» → D10 group scope. Вторично «Изменить» → D41, архив/удаление группы в редких действиях; удаление группы не удаляет знания.

Состояния: нормальный список; одна карточка вместо группы; пустой draft; не хватает активных members; архив/source missing; разорванная связь после удаления; loading/error/readonly; длинные названия и до 7 участников. Не проектировать сложную силовую mind map как обязательный способ управления. Не печатать исходные ответы на карте во время первого проверочного задания.

### D41 — Редактор группы и связей

Job story: «Когда нахожу общий смысл, хочу связать существующие знания и назвать основание связи».

Новая группа из D08 / edit из D40. Поля title/principle/condition; добавить существующие элементы темы (поиск); выбрать relation type и направление; своё объяснение; источник/метка пользователь/AI draft; пример/контрпример. Изменить порядок кнопками и поддержать клавиатуру, drag необязателен. Главный CTA «Сохранить» → D40. Back → D40 edit / D08 new со сбросом несохранённых правок по актуальным общим требованиям. Если сначала нужен новый item — D09 и понятный возврат в состояние группы внутри ещё открытого мастера; закрытие всего мастера сбрасывает ввод.

Состояния: 0/1 members, 2–7 валидны, попытка добавить 8-й с объяснением UI-лимита, неверная/замкнутая самоссылка, удалённый элемент, конфликт edit, ошибки сети, сохранение/успех. Ручные связи доступны Free. «Предложить с ИИ», если реализовано, перед вызовом показывает расход существующей квоты; при её отсутствии остаётся ручной путь, интерфейс не обещает бесплатную бесконечную генерацию.

## 5. Обязательные варианты учебного экрана

- `D11-Explain-First`: вопрос без источника и эталона, текст или режим self-check без записи голоса, явные «Не знаю/Помощь».
- `D12-Explain-Rubric`: first answer, 2–4 понятных критерия после попытки, критерий «не могу объяснить», кнопка к точечному источнику.
- `D11-Explain-Corrected`: источник закрыт, «Повтор после разбора», прошлый черновик доступен по желанию; assisted label, не новая независимая победа.
- `D11-Discriminate`: условие и выбор/ввод метода без заголовка-подсказки; последующий расчёт — отдельная часть.
- `D11-Relate`: найти общий принцип/различие/условие/ошибочную связь без готовой карты; «Открыть схему» = помощь.
- `D12-Relate-Feedback`: эталон связи, причина, provenance и метка проверки; нет автоматического «освоены все элементы».
- AI limit: до 300 токенов на текстовую grade; длинный ответ можно проверить самому или сократить без потери. Не изображать микрофон, аудиоплеер и транскрибацию.

Не выделять отдельные full-screen ID для каждой фазы: это варианты D11/D12 с одним session state и предсказуемым Back.

## 6. Прототипы для сдачи

1. Free: D08 → D41 manual → D40 → D10 → D11 relate → D12 self-check → D13; без paywall и LLM.
2. Объяснение: D11 first → D12 gap → D34 → close → D11 corrected assisted → D12 → D13; ответ не потерян, deferred independent review виден.
3. Чередование: intro нового типа → D10 mix → D11 discriminate → feedback → другой family; отдельный single-family fallback.
4. AI import: D18 принимает элементы/связь раздельно → D40 → practice; неверная AI-связь отклоняется, сами знания можно принять.
5. Ошибки: quota=0/AI timeout → self-check; missing source; связь на архивный item; stale edit; перезапуск сессии сохраняет фазу.
6. Адаптивность: все новые/изменённые состояния RU/EN, light/dark, 360/390/430 CSS px, 200% текст и keyboard; portrait/fallback и native Back из основных ТЗ.

## 7. Компоненты, тексты и аналитические аннотации

Компоненты: objective label, assistance label, rubric checklist, explanation gap card, relation row/type/direction, group member picker, queue-mode selector и insufficient-data metric. Эти компоненты переиспользуют текущие токены; новые illustrations/icons только при обоснованной необходимости, без нового персонажа.

Строки локализовать в существующей структуре miniapp.* и meta/bot/api/mcp по актуальному i18n контракту. Примеры: «Объясни своими словами / Explain in your own words», «Повтор после разбора / Retry after review», «Связать идеи / Connect ideas», «Выбрать способ / Choose an approach». Это рабочие RU/EN формулировки для согласования, не текст внутри raster assets.

Analytics annotations: intent → source/hint → submitted attempt → feedback → correction → session complete; objective, phase, grading mode, assisted и queue mode, без сырого ответа/текста книг. Для D40/41 — создание/редактирование/подтверждение связи отдельно от успешной учебной попытки. Haptic у сохранения и результата без наказания за ошибку.

Решение и полный UX-контракт: раздел 7.4 [ТЗ дизайнеру](01-designer-brief.md); данные и готовые тексты: [exercise-science-content.md](../research/exercise-science-content.md). Контракт реализации — раздел 7.4 [ТЗ разработчику](02-development-spec.md). Применять также актуальные общие требования 1.14: bottom sheets, изоляция жестов, анимации и сброс обычных форм. ### 9.1. Подача, данные и поведение

**Решение:** контекстное добровольное знакомство один раз на метод, затем компактный постоянный вход. Не открывать теорию принудительно перед упражнениями, не ставить прочтение условием онбординга/занятия/серии и не добавлять пять обязательных шагов. Цель D11 — выполнить упражнение; теория снимает сомнение «зачем», не конкурирует с вопросом и CTA.

**Первый контакт:** на D10 при первом предложении соответствующего метода, либо на D11 если пользователь миновал D10, показать спокойную карточку в первой видимой области под краткой инструкцией. Заголовок «Зачем это упражнение?», одна строка приглашения из контент-пакета, текстовая кнопка «Как это работает · исследования» и доступное «Позже». Карточка не перекрывает задание/клавиатуру и не скрывает «Ответить». Очерёдность внимания: вопрос/инструкция → учебное действие → научное приглашение. За одно посещение не показывать пачку из пяти карточек. До первой попытки нельзя раскрывать конкретный проверяемый способ/формулу: карточка теории общая, без ответа задачи.

**Повторное использование:** после открытия D42 и нажатия «Прочитал» либо выбора «Позже» расширенное приглашение по этому методу больше само не показывать; всегда остаётся видимая текстовая ссылка «Зачем это упражнение?» рядом с инструкцией, не иконка без подписи, не меню из трёх точек. Если пользователь начал задание вместо приглашения, оно сворачивается без повторного навязывания в следующей сессии. Статус «прочитал» не выводить из прокрутки/таймера: только явное действие; «позже» не равно «прочитал». Существенное обновление статьи помечается тихим «Обновлено» у ссылки без нового автопоказа. Один и тот же метод не представлять как новый при каждом упражнении или смене языка.

**Каждое упражнение:** D11 recall → M1, explain → M4, discriminate → M3, relate → M5; apply — связанный с реальной задачей метод (или честное описание применения без заявления об отдельном доказанном методе). M2 — сквозное расписание: вход «Почему повтор сейчас?» на D03/D10/D13 и дополнительная ссылка в D42. При смешанной практике активные методы перечислять внутри D42, не дублировать карточки. Если очередь не смешанная, M3 не приписывать. Для знакомства с новым материалом объяснять цель знакомства без заявления, что простое чтение само по себе retrieval.

**D42 «Зачем это упражнение?»** — единый контекстный bottom sheet `.large` (короткое приглашение в экране, теория только по тапу). Слева Close/Back по вложенности, по центру grabber и название; «Прочитал» — явное действие завершения знакомства, без обязательного checkbox/таймера. Содержание: 1) зачем и что делать — 2–3 предложения; 2) «Что проверяли» — участники/материал/сравнение/срок, где проверено; 3) «Что получилось» — конкретный результат; 4) «Что это значит здесь» — перенос в продукт и границы; 5) «Исследования» — авторы, год, название, DOI/первичный URL, язык и доступность текста. Нужный метод открыт сразу, другие методы — вторичный список внутри sheet. Теория доступна Free без AI и расхода квот, также из D01-Science и D33; онбординг содержит лишь необязательный вход «Почему это работает», не учебник перед стартом.

**Данные дизайнеру:** [готовые тексты пяти карточек, результаты опытов и ссылки](../research/exercise-science-content.md) обязательны для наполнения D42, не lorem ipsum; [реестр научных оговорок](../research/learning-methods-evidence.md) сохраняется. M1: эксперимент с иностранными словами, неделя, около 80% против 33–36%; M2: более 1 350 участников, факты и отсрочка до года, подходящий интервал зависит от отсрочки; M3: знакомство с типами математических задач, mixed vs blocked, тест через неделю; M4: 14 и 10 восьмиклассников, текст о кровообращении, прирост pre/post; M5: три шахматиста и структуры экспертизы, косвенное основание, не испытание нашего тренажёра. Цифры не превращать в обещания результата пользователя.

**Контекст и состояния:** открыть/закрыть D42 возвращает к тому же attempt, вводу, фазе, scroll и фокусу без submit/оценки/AI; общая методология не является помощью по содержанию. Нельзя вставлять готовый ответ/карту текущего задания в научную карточку. Внешняя статья открывается нативным поддерживаемым способом без потери контекста; ошибка ссылки не блокирует практику. Локальный пересказ доступен без обращения к сайту исследования. Сдать first/unseen, dismissed, acknowledged, revisited, updated, offline/source unavailable, длинную библиографию, RU/EN, две темы, крупный текст, reduced motion. Закрытие D42 жестом не сворачивает Mini App. Настройки знакомства — явное исключение из сброса форм, это preference, а не сохранённый ввод.
