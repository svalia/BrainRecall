# BrainRecall — контекст для Antigravity

Передача по поручению владельца, 11 ноября 2026. Задача: принять контекст и оба ТЗ, подтвердить прочитанные версии. Передача сама по себе не поручает разработку, публикацию или платные API-вызовы.

## Идея
Telegram Mini App для долгосрочного запоминания учебных материалов, применения знаний в жизни и внедрения привычек. Пользователь создаёт знания вручную либо импортирует текст/книгу с ИИ, выбирает цель, проверяет предложения со ссылками на источник и занимается короткими сессиями с припоминанием, интервалами и новыми ситуациями применения. Различать исследованность методов и ещё не доказанную эффективность приложения. Буквального «переноса из коры в автопилот» не обещать.

## Ключевые решения
- Разделы: Сегодня, Знания, Привычки, Материалы, Прогресс; профиль/настройки отдельно. D01 — продающий лендинг с научными источниками и бесплатным локальным демо.
- Ручной Free: 3 темы/3 привычки/500 активных знаний. Trial разовый 7 дней только после подтверждения первой ИИ-операции: 30k исходных токенов, 20 проверок, 5 кейсов, 1 план.
- Старт 499 Stars/30 дней: 10 тем/10 привычек/10k знаний, 200k исходных токенов, 200 проверок, 20 кейсов, 5 планов, 4 обзора. Про 1099: 50/30/30k, 600k/1000/100/20/4. Ручные операции и сохранённые упражнения не вызывают LLM.
- Stars recurring с явным согласием, отменой и серверным successful_payment. Квоты/платежи идемпотентны. После expiry данные читаются/экспортируются, активный набор ограничен Free. ИИ через заменяемый DeepSeek adapter, стоимость пока прогнозная.
- Привычки: сигнал, минимум, привлекательность, среда, награда и запасной план. Общая серия — за весь посильный DayPlan; нейтральные дни сохраняют без +1, пропуск без защиты сбрасывает current, сохраняет рекорд. Серии объектов отдельно.
- Достижения 1/3/7/14/30/60/100/180/365, календарь/рекорд, короткое отключаемое празднование, спокойный возврат. Нет XP/лиг/персонажей.
- Freeze: 1 бесплатно после первого earned, затем 1 каждые 7 lifetime earned; запас максимум 2 free+paid без очереди при переполнении. Покупка дня/недели XTR, неделя на даты, без накопления купонов; максимум 7 защищённых дат/rolling30. Frozen не растит счётчик; авторасход по opt-in без автооплаты. Цена freeze ещё не выбрана.
- Telegram safe areas динамические, hierarchical native Back, официальный HapticFeedback, portrait на поддерживаемых клиентах, responsive fallback. Grabber 38x5 в доступной верхней зоне; нативное сворачивание, публичный minimize() не подтверждён.
- Русский с локализацией сразу: canonical ru.json → будущие en.json, autodiscovery, /api/v1/i18n public subset. Нативные metadata/menu Telegram и языковые previews BotFather отдельно. Optional language_code, только проверенный initData на сервере, ручной язык приоритетен. Рабочий стек TS, Python filenames в пожелании — примеры модулей, не требование менять стек.
- Удаление аккаунта из профиля даже при автоматическом Telegram-входе: связанные данные/файлы, sessions, reminders и renewal; backup/обязательный платёжный аудит отдельно.
- Аналитика обязательна: vendor-neutral facade track/identify/user properties/reset → collector/outbox/adapters. Провайдер позже (Amplitude/GA4/Метрика/self-host PostHog); Metabase через read-only БД. Все пять интеграций заранее не строить. Сырые книги/ответы/PII не собирать.
- Владелец делает и поддерживает сам. Selectel около 3600 руб/мес на все проекты; не трогать чужие сервисы. Готовая реализация и макеты этим контекстом не подтверждены.
